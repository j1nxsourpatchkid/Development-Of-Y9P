Y9+ is a programming language built from scratch, designed with the goal of eventually
being able to build almost anything other modern languages can while being just as
fast, if not faster.

This has been an idea in the works for a while. Y9+ is still early in development,
but the long-term idea is a language that is fully capable, expressive, and
performant enough to stand alongside established languages.

File extension: `.y9`

## Status

Y9+ is in active development (Release 11). The toolchain includes the compiler,
runtime, static type checker, native test runner, formatter, and interactive REPL.

This manual reflects only what is currently implemented and working — see
`KNOWN_LIMITATIONS.md` for what doesn't exist yet.

## What this repo is

This is the **manual** — the rulebook for Y9+ syntax and language rules.

## Structure

- `KNOWN_LIMITATIONS.md` — honest list of what isn't built yet
- `MILESTONES.md` — feature checklist and roadmap to v1.0 / IDE
